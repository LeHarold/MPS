# MPS

亞洲／台灣地圖工作空間 PWA。靜態程式位於 `dist/`，不需建置即可用 HTTP 伺服器啟動。

正式網站：https://leharold.github.io/MPS/

## 本機啟動

```sh
python -m http.server 5192 --bind 127.0.0.1 --directory dist
```

瀏覽 `http://127.0.0.1:5192/`。PWA 離線功能需要 HTTPS 或 localhost。

## 使用

- 鐵捲尺依序選兩點；點擊距離標籤進入詳細修訂，可輸入距離並鎖定。起點保持固定，終點沿原方位調整；鎖定後拖曳端點亦維持長度。
- 修訂資料採逐點度分秒欄位，分別設定名稱、用途、顏色、高度（m）及備註。完整屬性隨專案 JSON 儲存；KML 支援其原有幾何、名稱、顏色及高度欄位。
- 尺規吸附已顯示的航點、航路點、自訂圖形頂點、參考圖層點及機場點。
- 圖層樣式的「點大小」依 100% → 75% → 50% → 25% 循環，與透明度分開控制。
- 「編輯位置」開啟位置編輯；使用上／下按鈕移動區段或工具，輸入相同群組名稱可組成下拉選單，再次按鈕結束並儲存。
- 「列印／PDF」預設 1:1,000,000，支援 A4、A3、Letter 及方向。列印採離線向量底圖與開啟的圖層，使用緯度等距投影：每 1° 緯度固定 60 NM；經度依中心緯度縮放。預覽地圖可拖曳平移，範圍會自動更新 PDF 且保持比例尺；再下載 PDF，列印必須選實際大小／100%，不要符合頁面。小比例尺及跨大緯度範圍仍有經向尺度差異。
- 資料來源與授權可於程式內對話窗閱讀，完整授權見 `dist/data-sources.html` 與 `dist/vendor/*.LICENSE`。

## 圓規、標籤與列印

- 尺規下拉選單包含直尺、圓形量角器與圓規，使用各工具實際外形的 SVG 圖示。
- 圓規點選圓心並輸入半徑；小十字圓心可點擊解鎖、拖動靠近可見點吸附。筆端雙擊按住拖動沿半徑畫弧，雙擊後直接放開則標點。
- 名稱與座標標籤長按後拖動，偏移隨專案保存。距離標籤沿線移動。
- 列印避讓僅移動標籤，保留文字尺寸；預設窄邊界（12.7 mm），另提供一般、適中、寬、無邊界和自訂。關閉頁尾後，地圖填滿所選邊界內。

## 離線打包

上方「打包離線網站」產生 ZIP，包含程式、向量圖資、所有目前圖層、儲存專案及已下載地形。排除衛星與街道圖磚；離線高度覆蓋範圍依已下載區域。

Windows 完整解壓後執行 MPS-Offline.exe，僅在 127.0.0.1 的 5278–5299 可用埠提供檔案並開啟瀏覽器，不需另裝 Node 或 Python。系統匣可退出服務。來源為 OfflineMPS.cs，使用 Windows .NET Framework 4 編譯；非 Windows 系統可用自己的 HTTP 伺服器開啟解壓後的目錄。瀏覽器資料不會寫回 ZIP，新增內容須另行儲存專案備份。

## 儲存及存取

專案與操作偏好儲存在各裝置、各網站來源的瀏覽器儲存空間；離線地形存於 IndexedDB。公開 GitHub 儲存庫保存程式、原始參考資料與測試，不會自動備份使用者瀏覽器內的專案。

白名單登入、一次性密碼、裝置授權、使用紀錄等後端功能依使用者決定延後，尚未啟用。GitHub Pages 目前公開提供使用。

## 驗證

```sh
node test-workspace.mjs
node test-coordinates.mjs
node test-v47.mjs
```

航空及地理資料為固定版本的公開參考資料，來源日期與授權隨 `data-sources.html` 記錄。
