# MPS

亞洲／台灣地圖工作空間 PWA。靜態程式位於 `dist/`，不需建置即可用 HTTP 伺服器啟動。

正式網站：https://leharold.github.io/MPS/

## 本機啟動

```sh
python -m http.server 5192 --bind 127.0.0.1 --directory dist
```

瀏覽 `http://127.0.0.1:5192/`。PWA 離線功能需要 HTTPS 或 localhost。

## 使用

- 鐵捲尺依序選兩點；點擊距離標籤進入詳細修訂，可輸入距離並鎖定。起點保持固定，終點沿原方位調整；鎖定後拖曳端點亦維持長度。
- 修訂資料採逐點度分秒欄位，分別設定名稱、用途、顏色、高度（m）及備註。完整屬性隨專案 JSON 儲存；KML 支援其原有幾何、名稱、顏色及高度欄位。
- 尺規吸附已顯示的航點、航路點、自訂圖形頂點、參考圖層點及機場點。
- 圖層樣式的「點大小」依 100% → 75% → 50% → 25% 循環，與透明度分開控制。
- 「編輯位置」開啟位置編輯；使用上／下按鈕移動區段或工具，輸入相同群組名稱可組成下拉選單，再次按鈕結束並儲存。
- 「列印／PDF」預設 1:1,000,000，支援 A4、A3、Letter 及方向。列印採離線向量底圖與開啟的圖層，使用緯度等距投影：每 1° 緯度固定 60 NM；經度依中心緯度縮放。預覽地圖可拖曳平移，範圍會自動更新 PDF 且保持比例尺；再下載 PDF，列印必須選實際大小／100%，不要符合頁面。小比例尺及跨大緯度範圍仍有經向尺度差異。
- 資料來源與授權可於程式內對話窗閱讀，完整授權見 `dist/data-sources.html` 與 `dist/vendor/*.LICENSE`。

## 搜尋、操作提示與備份

- 放大鏡或 Ctrl+K 開啟統一搜尋，支援航點、航路、參考及使用者圖層、物件名稱、具名頂點與十進位／度分秒座標。定位使用暫時亮線，不更動圖層開關。
- 地圖「目前」列持續顯示工具，展開可查看下一步操作，收起偏好隨專案儲存。
- 設定可開啟標籤避讓、選擇優先類型、是否隱藏擠不下的低優先標籤，以及 8–24 px 名稱／座標字體。避讓只移動位置，保留字體大小；手動位置及選取項目優先。移位標籤帶引線。
- 備份與還原集中在上方磁碟圖示。版本以 IndexedDB 保存，顯示台北時間、名稱及圖層數；可建立本機版本、下載 JSON、從檔案或版本還原。還原前先建立保護版本；舊命名專案仍可存取。本機版本不等於外部備份。

## 圓規、標籤與列印

- 尺規下拉選單包含直尺、圓形量角器與圓規，使用各工具實際外形的 SVG 圖示。
- 圓規弧線儲存為單一物件，取樣座標只用於線形，不建立取樣標記或逐點清單。收起圓規會回到平移，雙擊已儲存的弧線可修改詳細資料。
- 圓規點選圓心並輸入半徑；小十字圓心可點擊解鎖、拖動靠近可見點吸附。筆端雙擊按住拖動沿半徑畫弧，雙擊後直接放開則標點。
- 名稱與座標標籤長按後拖動，偏移隨專案保存。距離標籤沿線移動。
- 列印避讓僅移動標籤，保留文字尺寸；預設窄邊界（12.7 mm），另提供一般、適中、寬、無邊界和自訂。關閉頁尾後，地圖填滿所選邊界內。

列印提供 A4／A3 的常用版型及可自訂儲存的紙張、方向、比例尺、邊界、頁尾與校正線設定。50 mm 檢查線以 PDF 原生向量毫米座標繪製，並標示目前地圖單位對應的實際距離；紙本須以 100%／實際大小列印。

## 離線打包

上方「打包離線網站」產生 ZIP，包含程式、向量圖資、所有目前圖層、儲存專案、備份版本及已下載地形。排除衛星與街道圖磚；離線高度覆蓋範圍依已下載區域。

Windows 完整解壓後執行 MPS-Offline.exe，僅在 127.0.0.1 的 5278–5299 可用埠提供檔案並開啟瀏覽器，不需另裝 Node 或 Python。系統匣可退出服務。來源為 OfflineMPS.cs，使用 Windows .NET Framework 4 編譯；非 Windows 系統可用自己的 HTTP 伺服器開啟解壓後的目錄。瀏覽器資料不會寫回 ZIP，新增內容須另行儲存專案備份。

## 儲存及存取

專案與操作偏好儲存在各裝置、各網站來源的瀏覽器儲存空間；離線地形存於 IndexedDB。公開 GitHub 儲存庫保存程式、原始參考資料與測試，不會自動備份使用者瀏覽器內的專案。

目前使用加密簽章授權檔進行首次解鎖；帳號白名單、一次性密碼及使用紀錄等後端功能仍未啟用。GitHub Pages 的程式與靜態資源公開；前端授權無法防止修改程式繞過。

## 工作空間、游標與線段記號

工作空間預設 230 px，可在設定選 230／260／300／330 px。精簡模式隱藏輔助說明及英文標題，保留圖層名稱、計數與回饋。座標清單展開時才建立，減少手機載入與捲動負擔。

游標右方資訊分三行：經度、緯度、高度。獨立浮動顯示可避開視窗邊緣與主要操作元件；底部顯示方式保持原有單行。KML 點的名稱標籤與控制點亦可開啟資訊，關閉編輯後會清理選取狀態。

線段詳細資料可設定等距記號的間隔及數量，顯示理論最大數量與做最多後的餘距。記號沿多段線的累積距離配置；為維持效能，單線最多繪製 1000 個。設定存於同一線段物件，隨專案及離線包保留，不新增獨立標記物件。

## 授權與擴充工具

線上與離線來源首次使用都須載入 .mpslic 檔並輸入密碼。授權採 AES-256-GCM、PBKDF2-SHA256 310000 次及 ECDSA P-256 簽章；網站僅包含驗證公鑰。解鎖後將授權密文及不可匯出的解密 CryptoKey 保留於同來源 IndexedDB，因此不再依賴原始檔案。設定的「刪除授權並鎖定」移除解鎖與擴充工具，保留圖層及備份。

現有工具不個別管制；授權內可包含額外工具的名稱、圖示及 JavaScript code。擴充工具在 opaque-origin sandbox iframe 下的 Worker 執行，透過 getContext、pickPoint、input、addObject、fitBounds、notify 接口操作 MPS；程式不取得主頁 DOM、授權密碼或簽發私鑰。iframe／Worker 的 CSP 禁止外部連線。切換工具、Esc、到期或刪除授權會停止工具。

管理者簽發工具、私鑰、初始授權及密碼另存本機，不在此儲存庫及離線包中。保留簽發私鑰才能為此公鑰簽發新授權。授權檔與密碼須另外提供給離線使用者。

靜態網站的解鎖屬正常操作流程控制，不是後端防繞過或伺服器資源存取管制。

完整回歸檢查：`node run-checks.mjs`（14 組）；私密資料出貨檢查僅在管理者本機執行 `node check-private-material.mjs`。
